# shreyaadani.github.io

Personal portfolio site for Shreyaa Dani — Software Engineer & AI Systems Builder.

**Live at:** https://shreyaadani.github.io

## Structure

```
.
├── index.html        ← The entire site (single file, no dependencies)
├── assets/
│   ├── photo.jpg     ← Hero photo
│   └── resume.pdf    ← Downloadable résumé (add this file)
└── README.md
```

## Deploying

1. Create a GitHub repo named exactly `shreyaadani.github.io`
2. Push this folder's contents to the `main` branch
3. Go to **Settings → Pages → Source → Deploy from branch → main / root**
4. Live in ~2 minutes at `https://shreyaadani.github.io`

## Updating content

Everything is in `index.html`. Search for the section you want to edit.
No build step. No npm. No framework. Just save and push.

## Adding your resume

Drop your PDF as `assets/resume.pdf` — the download button is already wired up.

## Creatives section

The three placeholder cards are ready. When you want to fill them in,
find the `#creatives` section in `index.html` and replace the `.creative-slot` blocks.
